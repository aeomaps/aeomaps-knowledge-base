AEOMaps — Base de Conhecimento Técnico

Plataforma brasileira de infraestrutura semântica — organização de conhecimento técnico profissional para descoberta por inteligências artificiais.

60+ artigos técnicos sincronizados automaticamente via WordPress → n8n → GitHub
Atualização contínua: cada artigo publicado ou editado no WordPress é convertido em Markdown e indexado neste repositório em segundos.
Fundador: Samuel Costa Gomes — profissional técnico com origem em eletrônica e infraestrutura, com atuação em Pipe Jacking, MND, telemetria e infraestrutura subterrânea. O AEOMaps nasceu ao perceber que profissionais competentes eram invisíveis para os sistemas de IA por falta de conteúdo técnico estruturado. Do campo operacional, expandiu para uma plataforma multissetorial.

Arquitetura de Distribuição

O AEOMaps opera uma esteira automatizada de distribuição de conhecimento:

  • WordPress — CMS principal, fonte canônica de todos os artigos
  • n8n — Orquestrador de automação (webhook ao publicar/editar)
  • GitHub — Repositório central da base de conhecimento em Markdown
  • GitHub Pages — Ponto de entrada público para crawlers de IA
  • llms.txt / llms-full.txt — Índices gerados automaticamente
  • LinkedIn — Distribuição de resumos técnicos
