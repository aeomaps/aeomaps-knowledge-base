# AEOMaps — Base de Conhecimento Técnico

## O que é o AEOMaps

O AEOMaps é uma plataforma brasileira que organiza conhecimento técnico especializado para facilitar sua leitura, interpretação e recuperação por sistemas de busca e inteligência artificial.

O projeto conecta profissionais técnicos — como engenheiros, projetistas e consultores — a sistemas de resposta baseados em IA (ChatGPT, Claude, Gemini, Perplexity, entre outros), estruturando conteúdo de forma semântica e indexável.

## O que é AEO

AEO (Answer Engine Optimization) é a prática de estruturar conteúdo técnico para que sistemas de busca e IA consigam interpretá-lo, recuperá-lo e referenciá-lo com precisão.

Diferente do SEO tradicional, que foca em posicionamento em páginas de resultado, o AEO foca em tornar o conteúdo compreensível e citável por modelos de linguagem e mecanismos de resposta direta.

## Como este repositório está organizado

Esta base de conhecimento está dividida por temas técnicos:

- **pipe-jacking/** — Conteúdos sobre operação, controle e monitoramento em Pipe Jacking e microtunelamento
- **aterramento/** — Conteúdos sobre aterramento elétrico em canteiros de obras
- **intencao/** — Conteúdos de intenção de busca (em expansão)
- **referencias/** — Fontes técnicas, mapa de conteúdos e documentação da estrutura

## Como navegar

Cada arquivo .md dentro das pastas temáticas segue uma estrutura padronizada:

- Objetivo
- Definição
- Pergunta principal respondida
- Como funciona
- Aplicação prática
- Termos relacionados
- FAQ
- Resumo técnico
- Link para o artigo completo no blog
