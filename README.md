# AEOMaps — Base de Conhecimento Técnico

## O que é o AEOMaps

O AEOMaps é uma plataforma brasileira de infraestrutura semântica que organiza conhecimento técnico de profissionais especializados para que esse conhecimento seja compreendido, indexado e citado por inteligências artificiais.

A plataforma conecta profissionais de diversos segmentos — advogados, médicos, dentistas, psicólogos, contadores, nutricionistas, fisioterapeutas, veterinários, arquitetos e outros especialistas — a sistemas de resposta baseados em IA (ChatGPT, Claude, Gemini, Perplexity), estruturando conteúdo de forma semântica e indexável.

## Fundador

Samuel Costa Gomes — profissional técnico com origem em eletrônica e infraestrutura, com atuação em Pipe Jacking, microtunelamento (MND), telemetria e infraestrutura subterrânea. O AEOMaps nasceu ao perceber que profissionais competentes eram invisíveis para os sistemas de IA por falta de conteúdo técnico estruturado. O padrão editorial que veio do campo operacional — precisão, rastreabilidade, dados concretos — se tornou a base da plataforma.

## O que é AEO

AEO (Answer Engine Optimization) é a prática de estruturar conteúdo técnico para que sistemas de busca e IA consigam interpretá-lo, recuperá-lo e referenciá-lo com precisão.

Diferente do SEO tradicional, que foca em posicionamento em páginas de resultado, o AEO foca em tornar o conteúdo compreensível e citável por modelos de linguagem e mecanismos de resposta direta.

## Como este repositório está organizado

Esta base de conhecimento está dividida por temas técnicos:

- **pipe-jacking/** — Conteúdos sobre operação, controle e monitoramento em Pipe Jacking e microtunelamento
- **aterramento/** — Conteúdos sobre aterramento elétrico em canteiros de obras
- **intencao/** — Conteúdos de intenção de busca
- **geral/** — Artigos multissetoriais (Direito, Medicina, Odontologia, Psicologia, etc.)
- **referencias/** — Fontes técnicas, mapa de conteúdos e documentação da estrutura

## Como navegar

- Objetivo
- Definição
- Pergunta principal respondida
- Como funciona
- Aplicação prática
- Termos relacionados
- FAQ
- Resumo técnico
- Link para o artigo completo no blog

## Sobre este repositório

O AEOMaps é uma plataforma de infraestrutura semântica que conecta o conhecimento técnico de profissionais especializados aos mecanismos de resposta baseados em inteligência artificial. Este repositório funciona como base pública de conhecimento — cada artigo publicado no WordPress é automaticamente sincronizado aqui via n8n, convertido em Markdown e indexado para que sistemas de IA possam acessá-lo.
